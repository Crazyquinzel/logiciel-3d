============================================================
   MÉDAILLE PERSONNALISÉE — OUTIL DE PERSONNALISATION
============================================================

But : créer un fichier STL imprimable, personnalisé (prénom, mention,
forme et icône), sans rien taper — juste une petite fenêtre.


------------------------------------------------------------
ÉTAPE 1 — Installer Python (une seule fois)
------------------------------------------------------------
- Va sur  https://www.python.org/downloads/
- Installe Python 3.
- ⚠️ WINDOWS : COCHE « Add Python to PATH » pendant l'installation.


------------------------------------------------------------
ÉTAPE 2 — Lancer l'outil (à chaque fois)
------------------------------------------------------------
- WINDOWS : double-clique sur  «  Medaille_Windows.bat  »
- MAC     : clic droit sur  «  Medaille_Mac.command  »  > Ouvrir
La 1ère fois, l'outil installe tout seul "Pillow" (quelques secondes).


------------------------------------------------------------
ÉTAPE 3 — Créer la médaille (2 onglets)
------------------------------------------------------------
ONGLET « Médaille » :
  - Prénom : tape le prénom (ex. Lucas). Les prénoms longs se réduisent tout seuls.
  - Mention : liste rapide (PAPA, PAPI, MAMAN, MAMIE, TONTON, TATIE, PARRAIN,
              MARRAINE, PROF, MAÎTRE, MAÎTRESSE, ATSEM)
  - … OU mention personnalisée : tape n'importe quel texte (ex. CHAMPION,
              INFIRMIÈRE, JOYEUX ANNIVERSAIRE…). S'il est rempli, il remplace la liste.
  - Case « Garder le mot SUPER » : décoche-la pour une mention seule, centrée
              (ex. « JOYEUX ANNIVERSAIRE » sans le mot SUPER).

ONGLET « Forme & déco » :
  - Forme : Blason, Cercle, Hexagone, Cœur ou Carré arrondi.
  - Icône en relief : Aucune, Étoile, Cœur, Ballon de foot, Crayon, Marteau,
                      Clé (outils), Pomme, Couronne, Musique, Fleur (jardinage),
                      Voiture, Croix médicale.

Puis clique « Créer le fichier STL ».
➡️ Le fichier apparaît dans le sous-dossier « STL » et le dossier s'ouvre.
   (ex. medaille_super_prof_TOM_blason_crayon.stl)
Ouvre ce STL dans ton slicer (Cura, PrusaSlicer, Bambu Studio…) → impression.


------------------------------------------------------------
ASTUCE : TEXTE / ICÔNE EN DORÉ (Bambu Studio & co.)
------------------------------------------------------------
Le relief (prénom + mention + liseré + icône) culmine à 0,9 mm au-dessus
du corps. Ajoute un CHANGEMENT DE FILAMENT à la hauteur Z = 5,0 mm :
tout ce qui est au-dessus sort dans une 2e couleur (or/argent) →
effet médaille frappée, sans peinture.

Impression conseillée : DOS sur le plateau, relief vers le haut → aucun support.


------------------------------------------------------------
CONTENU DU DOSSIER
------------------------------------------------------------
- medaille_app.py ........ le programme
- DejaVuSans-Bold.ttf .... la police (NE PAS supprimer)
- Medaille_Windows.bat ... lanceur Windows
- Medaille_Mac.command ... lanceur Mac
- LISEZ-MOI.txt .......... ce fichier
- STL/ ................... créé automatiquement avec tes fichiers

Pour les pros du clavier — ligne de commande :
    python medaille_app.py PRENOM [MENTION] [FORME] [ICONE]
    ex : python medaille_app.py Tom PROF blason crayon
