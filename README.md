# Logiciel 3D

Un projet de modélisation et visualisation 3D.

## Fonctionnalités

- Chargement de modèles 3D
- Visualisation interactive
- Export en plusieurs formats

## Installation

```bash
npm install
npm start
```

## Utilisation

Lancez l'application et importez votre fichier 3D pour commencer.

## Contribuer

Les contributions sont les bienvenues ! Pour proposer une amélioration :

1. Forkez le projet
2. Créez une branche (`git checkout -b feature/ma-feature`)
3. Commitez vos changements (`git commit -m 'Ajout de ma feature'`)
4. Poussez la branche (`git push origin feature/ma-feature`)
5. Ouvrez une Pull Request
